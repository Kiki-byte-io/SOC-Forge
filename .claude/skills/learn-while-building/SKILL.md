# Learn while building

For the requested task:
1. Explain the underlying concept in beginner-friendly but technically correct terms.
2. Explain why SOCForge needs it and where it fits in the architecture.
3. Identify the files/configurations likely to change.
4. Give a small implementation plan and acceptance criteria.
5. Wait for approval before editing.
6. Implement only the approved scope.
7. Run tests or provide a safe verification procedure.
8. Summarize changes, risks, assumptions and remaining work.
9. Ask one short teach-back question about the most important concept.
Do not dump a full tutorial or several phases at once.
